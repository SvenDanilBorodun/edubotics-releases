# Sicherheitslücken melden / Reporting a vulnerability

**Deutsch.** Wenn Sie eine Sicherheitslücke in EduBotics gefunden haben, melden
Sie sie bitte vertraulich per E-Mail an **svendanilborodun@gmail.com** und nicht
öffentlich. Beschreiben Sie bitte, was betroffen ist, wie sich die Lücke
nachvollziehen lässt, und welche EduBotics-Version Sie verwenden. Wir bestätigen
den Eingang so bald wie möglich und informieren Sie über die Behebung.

**English.** If you found a security vulnerability in EduBotics, please report
it privately by e-mail to **svendanilborodun@gmail.com**, not publicly. Please
describe what is affected, how to reproduce it and which EduBotics version you
use. We acknowledge reports as soon as we can and keep you informed about the
fix.

Unterstützt wird jeweils die neueste veröffentlichte Version.
Only the latest published release is supported.
